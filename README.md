## 🚀 Featured Projects

### 🌾 [Crop Yield Prediction for African Agri-Food Systems](https://github.com/reda189/crop-yield-prediction-africa)
An end-to-end ML pipeline that predicts crop yield across **53 African countries (2000–2022)** from rainfall, temperature, fertilizer and land data (FAOSTAT and the World Bank).

- Data exploration, sampling, hypothesis testing and bootstrapping.
- A benchmark of 5 models: linear regression, Random Forest, XGBoost, LightGBM and CatBoost.
- **Final CatBoost model: test R² = 0.947.**

`Python` `pandas` `scikit-learn` `CatBoost` `XGBoost` `statsmodels`

### 💧 [Smart Rainwater Harvesting Systems](https://github.com/reda189/Data-Driven-Analysis-and-Predictive-Modeling-of-Smart-Rainwater-Harvesting-Systems)
Data-driven analysis and predictive modeling of smart rainwater harvesting systems.

### ♻️ [SmartWaste-AI](https://github.com/reda189/SmartWaste-AI)
A project design, written for the *Building AI* course, for a computer-vision system that classifies household waste in real time from a camera and tells the user how to dispose of it. It is planned as a CNN image classifier (TensorFlow/Keras) trained on the TrashNet dataset.
